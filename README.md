# Growlia — Frontend

Landing page de Growlia.es construida con Next.js 14.

## Estructura

```
app/
  page.tsx       — Página principal (landing)
  layout.tsx     — Layout con Google Fonts
  globals.css    — Estilos globales
public/
  favicon.svg    — Icono del sitio
```

## Despliegue

1. Subir a GitHub como repositorio `growlia-web`
2. Importar en Vercel
3. Conectar dominio `growlia.es`
